ML-Based Memory Prefetching

Page-aware · Segment-aware · Cache-aware · Confidence-adaptive · Lightweight ML — COA project dashboard

Interactive in-browser model of the same idea: a small cache, a delta-history predictor with a confidence score, and optional page / segment / cache gates. Streaming patterns never reuse a block, so without prefetching every access is a cold miss. It is a teaching demo (prefetches arrive instantly, one cache level) — the trained Random Forest / MLP numbers are on the Results tab.
